# Product Overview

## Purpose
React TIL (Today I Learned) is a frontend product listing application built as a learning project to explore React 19, TypeScript, and modern frontend tooling. It demonstrates feature-based architecture with clean separation of concerns.

## Key Features
- Product listing fetched from a backend API (`/api/products`)
- Real-time text search filtering across product names
- Category-based filtering
- Loading and error states with refetch capability
- Responsive UI styled with Tailwind CSS 4
- Proxy configuration to avoid CORS in development

## Target Users & Use Cases
- Developers learning React 19 patterns (hooks, state lifting, useCallback)
- Reference implementation for feature-based folder structure
- Study material for custom hooks, service layers, and component composition
- Base project for extending with new product management features
